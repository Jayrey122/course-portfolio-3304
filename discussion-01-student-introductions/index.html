Part 02: The Purpose of a Personal Site

I personally think that having a personal site is super cool. I created one for my last class and honestly I didn't get the grade that I hoped for. I am hoping with this class I can learn more and understand more with CSS and HTML. Something that really stood out to me that my last class didn't mention was combining them instead of it just being external. I really enjoyed reading "My Website is a Shifting House Next to a River of Knowledge." It was really interesting to read websites being compared to every day things like a room, shelf, garden, plant, puddle, and a rock. It really put it into perspective how a website can be portrayed. I think that learning actual HTML and CSS code is very important when creating a website. Sometimes AI can mess up and knowing these can help you see where the problem is and how to fix it. The world relies on AI so much now days and they aren't right all of the time. I can see where people can get a 404 code and not know where the issue is or how to fix it. I think that AI should be used as a tool to understand things, but not for AI to do the work for you. AI can be helpful with breaking down difficult concepts and explaining things that might be hard to understand. People have relied on AI to do the work for them and I just don't believe that that's why AI was created.
