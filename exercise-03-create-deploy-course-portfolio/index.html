Exercise 03: Create and Deploy Your Course Portfolio

In this project I established my web development environment and launched a live portfolio website using HTML, Visual Studio Code, and GitHub Pages. I began by cloning the repository to my local machine and opening it in VS Code to modify the projects root index.html file, replacing placeholder text with my personalized information and coursework layout. After saving my HTML updates I used GitHub Desktop to commit the changes with descriptive version control messages and push them to the remote repository. This workflow succeddfully deployed a clean, publicly accessible homepage that serves as the centeral live hub for all my development work this semester. Course Portfolio
