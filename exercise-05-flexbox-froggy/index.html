Exercise 05: Flexbox Froggy: Learning CSS Layout

For this exercise I played Flexbox Froggy an interactive game that uses CSS challenges to practice Flexbox.The assignment required completing at least the first 12 levels, but I completedd all 24 levels that were offerend.

What I Practiced

Each puzzle gave me an opportunity to experiment with CSS and see the results on the screen. The exercise focused on Flexbox properties such as justify-content and align-items. Working through the levels gave me practice choosing layout rules to move the frogs onto their matching lily pads.

Exercise Completion

I went beyond the minimum requirement by finishing the entire game. Completing all 24 levels gave me the opportunities to practice the concepts introduced throughout the exercise. This activity has a hands on way to explore Flexbox before applying it to layouts in my own webpage.
